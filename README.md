# ROVER 🤖

> This is a DIY robotics project built using an Unmanned Ground Vehicle (UGV) and a Raspberry PI to learn about robotics.\n
> 
## Status
Current phase: Hardware assembled

## Hardware
- Waveshare UGV Rover (6-wheel tank chassis) 
- Raspberry Pi 4B
- RPi Camera Module
- ESP32 driver board (onboard, handles motor control)
